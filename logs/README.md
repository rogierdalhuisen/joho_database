# Application Logs

This directory contains log files generated by the application.

## Log Files

- **`django.log`** - General Django application logs (INFO level and above)
- **`sync.log`** - Synchronization logs from API sync commands (E-grip, Assuportal)
  - This is where you'll find detailed validation warnings and errors
  - Check this file after running sync commands to see data quality issues

## Viewing Logs

```bash
# View the most recent sync log entries
tail -n 100 logs/sync.log

# Follow sync logs in real-time
tail -f logs/sync.log

# Search for warnings in sync logs
grep WARNING logs/sync.log

# Search for specific issues (e.g., date warnings)
grep "seems invalid" logs/sync.log
```

## Log Rotation

Logs automatically rotate when they reach 10MB. The system keeps the last 5 backup files.
